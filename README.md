# Reach Machine plugin

Install in Claude Code:

```
/plugin marketplace add reachmachine/rm-social-media-manager-plugin
/plugin install rm-plugin-v2
```

Version 2.0.0. All research runs on the Reach Machine server; this plugin only runs the steps.

## Install

In Claude Code (2.1.275 or later):

```
/plugin install rm-plugin-v2 --marketplace reachmachine/rm-social-media-manager-plugin
```
